# Effective Business Communication for Senior Leaders

A standalone, responsive HRC Learning & Development self-paced course. No build process, server, account, or external dependency is required.

## Open locally

1. Unzip the package.
2. Open `index.html` in a modern browser (Chrome, Edge, Safari, or Firefox).
3. Learner notes, knowledge-check success, and progress are saved in that browser using local storage.

## Deploy

Upload the complete `Effective-Business-Communication-Course` folder to any static web host, LMS web-content area, SharePoint site assets, or internal web server. Keep `index.html`, `styles.css`, `course.js`, and the `assets` folder together.

For an LMS that accepts web packages, upload the folder contents as a ZIP package. This is a standalone web course and does not currently emit SCORM/xAPI completion events; completion, including the printable summary, is tracked within the learner's browser.

## Branding and fonts

The course is styled with an HRC-style navy, teal, and gold palette and supports Proxima Nova. Place licensed font files in `assets/fonts/` using these names to activate them:

- `ProximaNova-Regular.woff2`
- `ProximaNova-Semibold.woff2`
- `ProximaNova-Bold.woff2`

If the browser already has Proxima Nova installed, it will use the local font automatically. Replace colors in the `:root` variables at the beginning of `styles.css` to apply final brand-palette values.

## Included learning flow

Welcome → Senior Leader Shift → Executive Presence → Strategic Clarity → Stakeholder Communication → Data to Story → Influence & Alignment → High-Stakes Conversations → CLEAR capstone → 30-Day commitment → Completion summary.

The course includes interactive reflections, saved practice responses, coaching debriefs after each submitted individual activity, three activity-gated knowledge checks, section learning acknowledgements, CLEAR and C.A.L.M. frameworks, navigation and progress persistence, completion status, active learning-time tracking, reset, and a print/save-to-PDF completion summary.

Knowledge checks remain hidden until the associated activity response is saved. For sections with a knowledge check, the learner acknowledgement unlocks after a correct response. For other sections, it unlocks after the individual activity is saved and the coaching debrief is revealed.

The final Completion section is locked until all learning segments have been acknowledged. Its on-screen and printable summary includes total active learning time, activity-completion percentage, successful-acknowledgement percentage, and the frameworks and concepts covered. Learners can also select a one-to-five-star rating, add comments, and open a prepared feedback email addressed to `learning@healthreconconnect.com`.
